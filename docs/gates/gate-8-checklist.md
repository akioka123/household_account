# ゲート8 チェックリスト: システムテスト・リリース判定（レシート金額抽出・生活費入力の詳細化）

- 使用スキル: `gate-check`（判定レポートは `docs/gates/gate-8-report.md` に作成）
- 判定方針: 1項目でもFAILなら総合不合格

| # | チェック項目 | 確認方法 |
|---|---|---|
| 1 | ゲート2〜7がすべて合格している | 各ゲートレポートを確認 |
| 2 | Docker環境で実際に起動し、マイグレーションが本機能分(010)まで適用される | `docker logs household-app`を確認 |
| 3 | 実ブラウザでMustストーリー(US-01, US-02, US-04)のゴールデンパスが動作する | Browserペインでの実施結果を確認 |
| 4 | ゲート5のCritical不具合（品目0件レシートの到達不能）が実ブラウザでも再発していない | 実施結果#3を確認 |
| 5 | 既存機能（集計タブ・生活費簡易入力）に本機能追加による回帰がない | 実施結果#5を確認、既存テストスイート180件通過(ゲート7)と合わせて判断 |
| 6 | コンソールエラーがない | 実施結果#6を確認 |
| 7 | Should(US-03貼り付け一括登録)・画像アップロードは自動テスト(単体21+結合21含む計180件)で担保され、重大な既知の不具合がない | ゲート6・7レポートを確認 |
| 8 | 証跡（ログ・DOM実測記録）が保存されている | `docs/evidence/system-test/`を確認 |
| 9 | Won't確定事項（US-05〜11）が実装に反映されている（外部API呼び出し・スマホレイアウト等がない） | ゲート4・5の確認結果を踏襲 |

## 不合格時の対応

- 差し戻し先: 該当ゲート（実装起因ならbuilder-impl、テスト起因ならbuilder-test）
