# ゲート6 チェックリスト: 単体テスト（レシート金額抽出・生活費入力の詳細化）

- 対応する作業指示書: `docs/work-orders/6-unit-test-order.md`
- 使用スキル: `gate-check`（判定レポートは `docs/gates/gate-6-report.md` に作成）
- 判定方針: 1項目でもFAILなら総合不合格

| # | チェック項目 | 確認方法 |
|---|---|---|
| 1 | work-order 2節の全観点（2-1〜2-4）に対応するテストケースが存在する | テストファイルと観点一覧を突合 |
| 2 | 4.4.4節の親`amount`再計算（追加・編集・削除それぞれ）がテストされている | テストケースを確認 |
| 3 | `get_receipts()`の絞り込み条件（`category="food"` かつ `location=""`、品目0件を含む）がテストされている | テストケースを確認（ゲート5の重大指摘の再発防止確認として重要） |
| 4 | 貼り付け一括保存のAll-or-Nothing挙動がテストされている | テストケースを確認 |
| 5 | TSVパーサの判定規則5つすべてに対応するテストケースがある | テストケースを確認 |
| 6 | Portのモックが`MagicMock(spec=<Port>)`パターンで既存規約に従っている | テストコードを確認 |
| 7 | `pytest tests/unit -q`が全件成功する | 実行ログを確認 |
| 8 | `pytest tests -q`（全体）で既存テストの回帰がない | 実行ログを確認 |
| 9 | `ruff check app tests`がエラーなし | 実行ログを確認 |
| 10 | Repository実装・router（結合テスト範囲）に対する単体テストが誤って作成されていない | git statusでファイル一覧を確認 |

## 不合格時の差し戻し
