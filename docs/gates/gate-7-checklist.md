# ゲート7 チェックリスト: 結合テスト（レシート金額抽出・生活費入力の詳細化）

- 対応する作業指示書: `docs/work-orders/7-integration-test-order.md`
- 使用スキル: `gate-check`（判定レポートは `docs/gates/gate-7-report.md` に作成）
- 判定方針: 1項目でもFAILなら総合不合格

| # | チェック項目 | 確認方法 |
|---|---|---|
| 1 | 4.3節のエンドポイント10本すべてに対応するテストケースがある | テストとエンドポイント一覧を突合 |
| 2 | `TestClient` + `app.dependency_overrides` でDBなしに動作している（実DB接続コードがない） | テストコードを確認 |
| 3 | レシート作成直後（品目0件）でも編集領域に到達できることがエンドポイントレベルで検証されている | テストケースを確認 |
| 4 | 貼り付け一括保存のAll-or-Nothing挙動がエンドポイントレベルで検証されている | テストケースを確認 |
| 5 | 画像アップロードの検証失敗時のエラー応答が検証されている | テストケースを確認 |
| 6 | 既存の生活費簡易入力エンドポイントの回帰確認が含まれる | テストケースを確認 |
| 7 | `pytest tests/integration -q`が全件成功する | 実行ログを確認 |
| 8 | `pytest tests -q`（全体）で回帰がない | 実行ログを確認 |
| 9 | `ruff check app tests`がエラーなし | 実行ログを確認 |

## 不合格時の差し戻し

- 差し戻し先: builder-test
