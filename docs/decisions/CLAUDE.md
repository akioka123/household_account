# docs/decisions/ 運用規約(ADR)

household_account プロジェクト固有の意思決定記録(ADR)を置くディレクトリ。

## ファイル名

`ADR-<3桁連番>-<内容を表す短い英語スラッグ>.md`(例: `ADR-001-receipt-image-validation-library.md`)。連番はゼロ埋め3桁で採番し、既存ファイルの最大連番+1を使う。

## フロントマター(必須)

**あとから機械的に参照・一覧できるよう、本文の前に必ず YAML フロントマターを付ける。** フロントマターのないADRを新規作成しない。

```yaml
---
id: ADR-002
title: 短いタイトル(本文見出しと同じ内容)
status: 検討中 | 承認済 | 却下 | 廃止
date: 2026-08-27
supersedes: null      # このADRが置き換える既存ADRのid(なければnull)
superseded_by: null   # このADRを置き換えた後続ADRのid(未使用ならnull。廃止時に埋める)
tags: [任意のキーワード]
---
```

- `status` が変わったとき(検討中→承認済 等)は本文の「日付: / 状態:」行と両方を更新する
- 既存ADRを別のADRが置き換える場合、古い方の `status: 廃止` と `superseded_by`、新しい方の `supersedes` を両方更新する

## 本文構成

ADR-001 に倣い、以下の見出しをこの順で書く(該当がなければ「なし」と明記し、見出し自体は省略しない):

1. `## 背景(Why)`
2. `## 決定(What)`
3. `## 実施方法(How)`
4. `## 採らなかった選択肢と理由(Why not)`
5. `## しないこと(スコープ除外)`
6. `## 再検討条件`
