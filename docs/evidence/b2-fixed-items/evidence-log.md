## 3. 同一年月の重複履歴の是正（マイグレーション009）

`fixed_item_histories` に **同一 `fixed_item_id` で `effective_from` が重複する行**が存在する。

```
fixed_item_id | name | id | effective_from | amount
1 | 実家 | 21 | 2026-05 | 60440
1 | 実家 | 23 | 2026-05 |     0
2 | 家賃 | 22 | 2026-05 |     0
2 | 家賃 | 24 | 2026-05 | 60440
```

`FixedExpenses.get_effective_histories()` は `effective_from` の比較に厳密な `>` を使うため、同着の場合は**リストの先頭に来た方（= idの小さい方）**が採用される。結果として、後から登録した id=24（家賃 60,440円）ではなく id=22（家賃 0円）が採用され、家賃が「運用終了」と判定されている。

結果として、**同月内に入力を訂正しても、後から入れた訂正が黙って無視されていた**。上表では家賃の id=24（60,440円）が id=22（0円）より後の操作であるにもかかわらず、家賃が「運用終了」と判定されていた。

`incomes` / `card_statements` / `cash_balances` / `month_notes` は `year_month` に一意制約を持ち、ユースケースも upsert になっている。`fixed_item_histories` だけが一意制約を持たず、`add_fixed_item_history` が常に INSERT していた。

### 対処（ユーザー承認済み: 同月内の訂正は上書き）

- マイグレーション `009_add_unique_to_fixed_item_histories.py`
  - 各 `(fixed_item_id, effective_from)` で最大IDの行（＝最後の操作）のみ残して重複を削除
  - `UNIQUE(fixed_item_id, effective_from)` を追加
- `SqlAlchemyFixedItemHistoryRepository.save` を upsert 化（既存行があれば金額・カード・カード請求含有を上書き）
- `FixedItemHistoryModel` に `UniqueConstraint` を追加

### 適用結果（実DB）

適用前にテーブルを `pg_dump --data-only` でバックアップ（14行）。

```
alembic upgrade head   -> Running upgrade 008 -> 009
```

行数 14 → 12。削除されたのは id=21（実家 2026-05 60440）と id=22（家賃 2026-05 0）で、いずれも後続の操作に置き換えられた古い行。

| | 適用前 | 適用後 |
|---|---|---|
| 2026年8月の有効な固定費 | 実家 60,440円 / 投資信託 35,000円 / 保険料 17,324円 | **家賃 60,440円** / 投資信託 35,000円 / 保険料 17,324円 |
| 運用終了済み | 家賃 | **実家** |
| 月額合計 | 112,764円 | **112,764円（不変）** |

月次集計（`/month/2026/8/tab/summary`）:

```
固定費合計 112,764円 / 変動費合計 171,000円 / 当月損益 -283,764円
```

適用後、本流コンテナ（8000、旧コード）と worktree コンテナ（8001、新コード）の双方で上記が一致。**損益の数値に影響なし**。

可逆性:

```
alembic downgrade -1 && alembic upgrade head   -> 両方向とも成功、最終 version_num = 009
```

※ `downgrade` は一意制約を外すのみで、`upgrade` で削除した重複行は復元しない（マイグレーション内に明記）。復元が必要な場合はバックアップから戻す。

### 残る注意点

このブランチをマージするまでの間、本流のコード（常に INSERT する `save`）が一意制約付きのDBに対して同一年月の固定費履歴を登録すると、**従来の「黙って無視」ではなく IntegrityError になる**。DBを共有しているため、マージ前に本流側で同月の固定費履歴を登録する操作は避けること。
