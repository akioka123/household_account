# ローカル家計簿アプリ 要件定義書（A4・1枚）

## 1. 目的・スコープ
- 引っ越し後の家計を**年月単位**で記録し、**月次損益**と**年次推移**を可視化するローカルアプリを提供する。
- 技術方式：**Python / FastAPI + htmx**（ローカル運用、単一ユーザ想定）

## 2. 用語定義
- **変動費**：当月の「カード支出（カード別）」＋「現金支出（差分計算）」の合計（カテゴリ配賦なし）
- **固定費**：固定費マスタに登録された費用。削除するまで毎月自動計上される（削除＝金額0で履歴積み上げ）
- **カード支出**：カードごとの当月請求総額（複数カード可）
- **カード請求に含まれる固定費**：固定費マスタにフラグを持ち、**カードごとに紐づけ**てカード支出から控除する対象

## 3. 機能要件（画面・操作）
### 3.1 年次ダッシュボード（/dashboard/{year}）
- 年内（月別）の推移をグラフ表示（横軸：年月、縦軸：金額）
  - 手取り収入、支出（固定費/変動費）、損益
- 年収推移を表示（年単位）
  - 年収（額面）／年収（手取り）※いずれも月例＋賞与合算
- 月一覧から月次画面へ遷移

### 3.2 月次画面（/month/{year}/{month}）
- タブ（htmx部分更新）
  - 集計：当月の収入・支出・損益、入力不足（例：次月月初現金未入力）警告
  - 変動費：カード請求（カード別）登録
  - 現金：月初現金・当月引出（複数）・次月月初現金 登録
  - 固定費：固定費マスタの登録・変更・削除（＝金額0で新規履歴）
  - 収入：月例給与（額面/手取り）・賞与（額面/手取り）登録

### 3.3 設定（/settings）
- カード管理（追加・名称変更・無効化）
- 上限件数：変動費/固定費とも**初期最大20件**（設定で変更可）
  - ※本要件ではカテゴリ配賦なしのため「変動費20件」は「カード数等の登録上限」として適用

## 4. データ要件（永続化）
- DB：SQLite（ローカル）
- 主なエンティティ
  - Card（カード）
  - YearMonth（月単位の集計キー）
  - CardStatement（年月×カード：請求総額）
  - CashBalance（年月：月初現金）
  - Withdrawal（年月：引出明細）
  - Income（年月：給与/賞与の額面・手取り）
  - FixedItemHistory（固定費の履歴：適用開始年月、金額、カード紐づけ、カード含有フラグ）
- 固定費の終了日は持たない。削除は「金額0の履歴を追加」で表現する。

## 5. 計算仕様（自動算出）
- 現金支出（当月）  
  `cash_spent(ym) = cash_start(ym) + sum(withdrawals(ym)) - cash_start(next_ym)`  
  ※`cash_start(next_ym)`未登録の場合は当月の現金支出を未確定扱いとし警告表示
- 固定費合計（当月）  
  `fixed_total(ym) = Σ fixed_amount where effective_from <= ym （履歴から当月時点の金額を採用）`
- カード変動費（当月）  
  `variable_card(ym) = Σ card_statement(ym, card) - Σ fixed_in_card(ym, card)`（カードごとに控除）
- 変動費合計（当月）  
  `variable_total(ym) = variable_card(ym) + cash_spent(ym)`
- 損益（当月）  
  `profit(ym) = (salary_net + bonus_net) - (fixed_total(ym) + variable_total(ym))`
- 年収（年次）  
  `annual_gross = Σ(salary_gross) + Σ(bonus_gross)`、`annual_net`も同様

## 6. 非機能要件・制約
- ローカル運用（localhost前提）、単一ユーザ、認証なし
- データ保全：SQLiteファイルのバックアップ/エクスポート手段を提供（CSVまたはDBファイル出力）
- 整合性チェック
  - カード変動費が負値になる場合は警告（固定費フラグ/紐づけ/請求額の矛盾）
  - 次月月初現金未入力は当月現金支出未確定として警告

## 7. 受入基準（抜粋）
- 任意の年月を登録し、月次損益が自動計算されること
- 固定費を履歴管理（適用開始月）でき、削除時は金額0で以後反映されること
- 複数カードに対して、カード別請求額とカード紐づけ固定費控除が正しく計算されること
- 年次ダッシュボードで月次推移グラフと年収推移が表示されること
